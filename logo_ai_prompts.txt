TIPS
=====================================================================
1. AI image tools frequently misspell text. Best workflow:
   generate the MARK ONLY (Prompt 2), then add the "Nuvforge" wordmark
   yourself in Canva / Figma / Illustrator using real Sora SemiBold.
   That guarantees correct spelling and true brand typography.

2. Always check the spelling: "Nuvforge" — capital N only.
   Not NuvForge, not Nuforge, not Nuvforce.

3. If a tool ignores hex codes, describe them in words:
   "very dark navy blue almost black", "bright turquoise teal",
   "light silver gray".

4. Ask for SVG output if your tool supports it (Recraft, Illustrator AI,
   Vectorizer.ai). Otherwise generate PNG at the largest size available
   and vectorize afterwards.

5. Add "--ar 16:9" for horizontal lockups and "--ar 1:1" for icons
   if you are using Midjourney. Add "--style raw" for cleaner,
   less decorative results.

6. Generate 4+ variations of each prompt, then pick and refine.
